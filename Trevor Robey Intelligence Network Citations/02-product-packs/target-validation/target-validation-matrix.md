# DATA DICTIONARY: TARGET VALIDATION PACK

**Platform Integration:** Snowflake Information Schema / AWS Data Exchange
**Schema:** OPENCLAW_BIOMED.PUBLIC
**Table:** TARGET_VALIDATION_MATRIX

| Column Name | Data Type | Nullable | Business Definition & Validation Logic |
| :---------- | :-------- | :------- | :------------------------------------- |
| TARGET_ID | VARCHAR | FALSE | Unique alphanumeric identifier for the biological target (e.g., Ensembl ID). |
| DISEASE_INDICATION | VARCHAR | FALSE | Standardized disease nomenclature (e.g., ICD-10 or SNOMED CT classification). |
| EVIDENCE_SCORE | FLOAT | FALSE | Deterministic score (0.0 to 1.0) quantifying the strength of the genetic/molecular association. |
| CITATION_DENSITY | INTEGER | FALSE | Count of unique, verified primary literature sources supporting the target-disease link. |
| PRIMARY_PMID_ARRAY | VARIANT | FALSE | JSON array containing PubMed Unique Identifiers for immediate auditability. |
| PHARMACO_MODULATION | VARCHAR | TRUE | Mechanism of action required for therapeutic effect (e.g., Antagonist, Agonist). |
| PROVENANCE_HASH | VARCHAR | FALSE | SHA-256 cryptographic hash generated by the Phase 28 Ledger for compliance auditing. |

## Data Preview & Security Guidelines (For Public Marketplace Listing)

- **Dynamic Data Masking:** Strict data masking policies are enforced on the EVIDENCE_SCORE and PRIMARY_PMID_ARRAY columns for all non-entitled viewer roles. Prospective buyers will see the structure but not the proprietary scoring algorithms or the underlying literature mapping.
- **Sample Data Curation:** Sample data provided in the Snowflake Data Preview UI will reflect historical, widely known, and publicly verified target validations (e.g., the targeting of EGFR in Non-Small Cell Lung Cancer). This demonstrates table structure and interoperability without leaking proprietary alpha regarding novel, unpriced biological targets.

## Integration Notes

- All rows include a `PROVENANCE_HASH` linking to the append-only Phase 28 Direct-Delivery Evidence Ledger
- Citation arrays are validated against PubMed API at ingestion time
- Evidence scores are deterministically computed from citation density, study quality weighting, and replication count
- Schema is compatible with Snowflake Secure Data Sharing and AWS Data Exchange subscription verification
