## 2 · Reading the matrix

- **Tenant state** — `ON` / `OFF` / `PARTIAL` / `N/A` with the read date. "Inherited from root" = set at the
  root OU and flowing through the work OU into the browser OU; "Google default" = **not set anywhere in the
  tree**, so Chrome uses its own built-in default and **no policy is pushed** (a personal, consumer profile
  therefore keeps its consumer default — this distinction drives P5).
- **Recommendation** — `ADOPT` (proposal in §4) · `ADOPT-LATER` · `DECLINE` (with the reason) · `KEEP` ·
  `USE` (a report, nothing to configure).
- **Blast radius** — decision 1: a root/work-OU setting reaches the **personal profiles** through the browser
  OU; decision 3: anything the local profile pins cannot be changed from the cloud.
- Console paths use the tenant's menu (`Chrome browser → …`); the Workspace-style path
  (`Devices → Chrome → …`) is the same page. Verified routes in §6.
