# Free Sample — Trial Graveyard Feed (glioblastoma)

This free sample contains the first 5 of 390 stopped trials in the glioblastoma feed (as of 2026-07-30), in the identical schema, so you can evaluate data quality and format before subscribing.

The paid subscription delivers the **complete** register for the ClinicalTrials.gov condition query "glioblastoma" — all 390 of the 390 terminated/withdrawn/suspended trials the registry counted — refreshed **monthly**.

**Protocol-churn coverage.** Amendment-risk and protocol-churn columns are populated for 40 of 390 rows. Protocol history must be fetched one trial at a time from ClinicalTrials.gov, so it is sampled deliberately rather than run across the whole register; rows outside the sample carry the trial and its stop reason, with the churn columns empty.

**Condition search is term-based.** A different name for the same indication returns a different set (measured 2026-07-30: "NSCLC" returns 1,401 records where "non-small cell lung cancer" returns 1,391). Completeness above is for the term queried, not for every way the indication can be named.

Every row resolves to a public ClinicalTrials.gov record; no PHI.
