GROUNDED-CITATION GATE — WHAT SHIPS AND WHAT DOESN'T

Every cited identifier (PMID, NCT, ChEMBL CID, DOI) is cross-checked against the union of identifiers actually returned by live database tool calls during the same run — not model memory. If the grounded-citation ratio falls below the configured threshold, the report hard-fails PHASE30_CITATION_UNVERIFIED and does not ship.

Cited DOIs are screened against Crossref's retraction record before delivery. A report citing any confirmed retracted paper hard-stops PHASE30_CITATION_RETRACTED. The screen is fail-soft: a Crossref network error yields checked:false and does not wrongly block a passing report.

Retraction screening applies to cited DOIs only — PMIDs and NCTs are not routed through Crossref.

· Every Failed Trial Archaeology bundle ships a graveyard-memo.md: a structured memo of terminated, withdrawn, and suspended programs in the indication, fetched from ClinicalTrials.gov API v2 at run time · Each entry includes the sponsor's stated stop reason — or an explicit "(none stated by sponsor)" when ClinicalTrials.gov has no text; stop reasons are never invented · Protocol amendment-risk band (LOW / MODERATE / HIGH) derived from ClinicalTrials.gov change-history version counts across comparable stopped programs — a historical signal, not a forecast · Every NCT resolves to a live clinicaltrials.gov/study/NCT... link · Rendered deterministically from live CT.gov records — no LLM narration of stop reasons
SAFETY SIGNALS FROM LIVE DATABASES — NOT MODEL RECALL
· The pharmacovigilance workflow queries FAERS, DailyMed, RxNorm, and DrugSafetyAnalyzer at runtime via ToolUniverse (~2,116 biomedical tools, Harvard MIMS, Apache-2.0) · Adverse event signals are sourced from the databases actually queried at runtime — not interpolated from training data · A Reproducibility Manifest ships with every bundle: each cited identifier stamped VERIFIED / UNRESOLVED / UNCHECKED with its HTTP status and resolved URL

Reports are research artifacts produced using AI-assisted research synthesis with human editorial oversight; every cited identifier is a real public identifier you can verify in its source database. For research and informational use only — not clinical decision support, and not a basis for prescribing, diagnostic, or regulatory decisions. No PHI is hosted, transmitted, or processed. External publication, marketplace submission, customer delivery, and authentication actions remain manual-only by architectural design; the system does not act autonomously on external systems.

Citations are grounded in the retrieved source records, DOI retraction-screened via Crossref, and re-resolved per identifier (PMID, NCT, DOI) against the issuing public registry at delivery, with each result recorded in a reproducibility manifest. Re-resolution confirms an identifier resolves to a real source record; it does not validate the source’s scientific conclusions.
