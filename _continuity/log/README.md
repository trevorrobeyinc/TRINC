# `_continuity/log/` — archived board cycles

When the live `../CONTINUITY.md` Log grows long, older entries are rolled over into dated files
here so the live board stays lean and fast to read.

- One file per rollover: `CONTINUITY-<YYYY-MM-DD>.md`.
- Only the **Log tail** is archived — Current focus / Active workstreams / Parking lot always stay
  on the live board.
- The live board keeps a one-line pointer to the newest archive.

See `../README.md` → "Keeping the board lean — rollover" for the procedure.
